Privacy

This website runs on the same computer as the Catharsis server. It does not use advertising or third-party analytics.

This page does not ask for a username. You choose your name inside the game. The site does not store it.

The game connects to the server on this computer. Requests from the client to other game networks are blocked by this site.

The game explorer reads public chain data for the contracts this world already uses. It does not ask you to sign, and it does not embed videos from other sites.

The world itself stays on the server. Joining does not create an account on this website.
