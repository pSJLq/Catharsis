Where are the mechanics written down?

The guide covers the island, the bag, collections, crafts, spells, and the places that are still shut.

How do I play?

Press Play. The world is already selected. When the game finishes loading, click Done inside it, then click the window once. Esc gives the cursor back.

Where do I type my name?

Inside the game. This site does not ask for it and does not store it. Each player has their own name.

Sprint and the keyboard

Ctrl is sprint and W is forward. While the game window has the keys, that pair no longer closes the browser tab. The tab’s own close button still does. Esc releases the mouse. Space stays in the game instead of scrolling the page.

Can a friend join?

Open this page on this computer and press Play. Everyone on this world shares the one island.

Does full screen take the tab?

No. Full screen covers the game window. The site address stays in the bar.

What does the game explorer show?

Recent game actions on Shannon: gathering, crafting, invites, and spells. Search a transaction or an address. It only reads. Sign in the game.

What are the smart contracts?

Five addresses on Shannon testnet: the island, the bag, gear traits, spell words, and the void sword. The contracts page lists them. This site only reads them.

Where is the server address?

It is not printed on the site. Play fills it into the game window.
