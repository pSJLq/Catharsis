Questions

How do I play?

Press Play. When the game finishes loading, click Done inside it. Click the window once so the mouse and keyboard stay in the game. Esc gives the cursor back.

Where do I type my name?

Inside the game. This page does not have a name field, and it does not store the name you choose.

Can a friend join?

Open this page on this computer and press Play. Everyone on this world shares the one island.

What is the explorer?

A list of recent game actions on Shannon: gathering, crafting, invites, and spells. It does not sign anything.
